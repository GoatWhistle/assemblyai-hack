# Baselines

Три файла в этой папке — состояние ratchet-проверок. Формат у всех одинаковый: строки `<число> <путь>`, по одной на файл или пакет, который **уже** превышает лимит на момент фиксации базы. Пустой файл означает, что не превышает ничто, и это нынешнее состояние всех трёх.

| Файл | Проверка | Что в числе |
|---|---|---|
| `file-length.txt` | `make file-length` | строк в файле при лимите 250 |
| `package-size.txt` | `make package-size` | файлов в каталоге при лимите 20 исходников и 30 тестов |
| `ascii.txt` | `make ascii` | строк с не-ASCII символами при правиле «код только на английском» |

Смысл ratchet, а не обычного лимита: превышение, которое уже есть, фиксируется и не ломает сборку, но **счётчик двигается только вниз**. Новый файл сверх лимита падает сразу; существующий нельзя раздуть ещё сильнее.

`make baseline-file-length`, `make baseline-package-size` и `make baseline-ascii` перезаписывают базу текущим состоянием. Это осознанное действие: после него проверка перестаёт ловить то, что ловила раньше, поэтому вызывать их стоит только когда превышение принято сознательно и объяснено.

Комментариев внутри самих файлов нет по правилу из [CLAUDE.md](../../CLAUDE.md) — `#` в конфигурации запрещён, и объяснение живёт здесь, а не в заголовке каждого файла.
