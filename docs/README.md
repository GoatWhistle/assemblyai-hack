# AssemblyAI Voice Agent Hackathon — исследование и решение

Данные собраны 11 сентября 2026. Хакатон идёт 1–30 сентября 2026, дедлайн **30 сентября 18:00 MSK**.

---

## Ответ в четырёх строках

1. **Берём [RxGate](cases/rxgate.md)** — голосовой приём рецептов, который не пускает в заказ значение без подтверждения валидатором или голосом.
2. **Плюс два усиления** из отклонённых идей: агент-звонящий из [Harness](cases/harness.md) как `scripts/` для живых замеров, и `turn_detection` как характер персонажа из [Lingua Sola](cases/lingua-sola.md).
3. **Решение пересматривается один раз, на дне 2:** замерить speaker attribution accuracy на трёх голосах. Различает уверенно — переключаемся на [Bridgekeeper](cases/bridgekeeper.md).
4. **Побеждает дисциплина, не экзотика.** Обоснование — ниже.

## Тирлист идей

Оценки по четырём равнозначным критериям судейства. Каждая идея проработана до кейс-документа с архитектурой, планом на 19 дней и честной самооценкой.

| Тир | Идея | Tech | Present | Business | Original | Σ | Вердикт |
|---|---|---|---|---|---|---|---|
| **A** | **[RxGate](cases/rxgate.md)** — приём рецептов со шлюзом подтверждения | 8 | 8 | **9** | 7 | **32** | ✅ **Берём.** Ровный профиль, низкая дисперсия, деградирует плавно |
| **A** | **[Bridgekeeper](cases/bridgekeeper.md)** — контроль целостности смысла у живого переводчика | **9** | 7 | 8 | **8** | **32** | ⚠️ **Резерв.** Тот же балл, выше потолок, но риск не снимается кодом |
| **B** | **[Lingua Sola](cases/lingua-sola.md)** — голосовая иммерсивная среда | 8 | 8 | 5 | **9** | 30 | 🎲 Только если жюри точно отдаст слот за «самое интересное» |
| **C** | **[Harness](cases/harness.md)** — агент тестирует других агентов | **9** | 6 | 5 | 5 | 25 | ❌ Отсеян: два слабых критерия из четырёх + занятая ниша |

Полное сравнение с профилями рисков — [decision.md](decision.md).

### Почему RxGate, а не Bridgekeeper при равном балле

| | RxGate | Bridgekeeper |
|---|---|---|
| Как доказывается ошибка | **Арифметикой**: DEA mod-10, NPI Luhn+80840. Спорить не с чем | Суждением: «пропуск смысла» — любой held-out можно оспорить |
| Кто составил adversarial-набор | **ISMP и FDA**, с документированным клиническим ущербом | Мы сами |
| Главный риск | `domain=medical-v1` даёт или не даёт дельту — в обоих случаях это публикуемое число | Диаризация трёх голосов. **Не устраняется кодом** |
| При нехватке времени | Теряет функции, ядро демонстрируемо всегда | Рассыпается: диаризация на критическом пути |
| Прямой конкурент | Нет сильного | **Saakshi** — сильнейший проект поля на том же ядре |

### Что забираем из отклонённых идей

- **Из Harness:** агент-звонящий с враждебными сценариями как `scripts/` внутри RxGate (+2–3 дня). Корпус перестаёт быть набором WAV-файлов, латентность мерится живым разговором. Не заводится к дню 12 — вырезаем, ядро не страдает.
- **Из Lingua Sola:** `turn_detection` как выразительное средство — `min_silence` 400 мс у торопливого врача против 1800 мс у медсестры, сверяющейся со списком. Личность задаётся параметром API, а не текстом промпта. Так не делает никто.

## Почему у нас реальные шансы

Арифметика: **720 команд → 45 сдавших → серьёзных около десяти → 5 призовых мест.**

Главный фильтр — просто доделать и сдать. Второй — не иметь дыр, на которых поле уже теряет очки:

| Дыра поля | Поймано | Источник |
|---|---|---|
| Мёртвое или неправильное демо | **12 из 45** | [demo-health.md](demo-health.md) |
| Нет измеренной латентности | **44 из 45** | [competitors.md](competitors.md) |
| Нет работающего CI | **45 из 45** | [stack-and-code.md](stack-and-code.md) |
| Расхождение заявки и кода | минимум 6 | [competitors.md](competitors.md) |
| Противоречивые или сфабрикованные цифры | минимум 3 | [competitors.md](competitors.md) |
| Лидеры по голосам не упоминают AssemblyAI в README | #1 и #2 | [competitors.md](competitors.md) |

И главное: **AssemblyAI 8–9 сентября, в середине хакатона, опубликовала рамку оценки голосовых агентов** — Entity Error Rate вместо WER, caller repeat rate, процентили латентности по компонентам, close codes 3007/3008/3009. Её не применил никто из 45. Разбор — [assemblyai-signals.md](assemblyai-signals.md).

Свободные фичи API: word-level timings — 2 проекта из 45, speaker labels — 3, LeMUR — 2, code-switching как несущая функция — 1. Карта — [assemblyai-feature-usage.md](assemblyai-feature-usage.md).

## Обязательно в любом варианте

Независимо от выбранной идеи:

- [ ] Работающее демо **не на бесплатном Render**, проверенное в инкогнито с чужого устройства
- [ ] Judge-solo режим: один человек, без второго говорящего, возможно без микрофона
- [ ] Названная модель и верный эндпоинт; заявка и README не противоречат друг другу
- [ ] Ни одной цифры без методики и команды воспроизведения
- [ ] Held-out метрика, а не только регрессионная выборка
- [ ] Тесты и CI с зелёным бейджем
- [ ] Видео с таймером на экране
- [ ] MIT-лицензия, публичный репозиторий
- [ ] Гибрид двух сокетов: `transcript.user` в Voice Agent API приходит текстом **без** `words[]`, так что Streaming STT обязателен для confidence и таймкодов
