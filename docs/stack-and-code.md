## Что видно из этих цифр

### 1. Голоса сообщества не связаны с объёмом работы

Лидер по голосам — SAUTI AI (11 голосов) — это 42 KB кода и 8 коммитов. Второе место, Siberia Voice Agent (8 голосов) — 42 KB на PHP, 5 коммитов. При этом Saakshi (724 KB TypeScript, 11 коммитов, тесты, latency-замеры) стоит ниже в голосовании, а SmartLink (3,5 MB, 56 коммитов) — с одним голосом.

Голоса измеряют размер студенческого/локального сообщества автора, а не продукт. Судейство идёт по четырём заявленным критериям, и голоса в них не входят. Значит: тратить время на раскрутку голосов — почти бессмысленно, тратить его на инженерию и презентацию — осмысленно.

### 2. Настоящих тяжёлых проектов мало

Выше 400 KB и/или больше 25 коммитов: SmartLink, VerbaTrace, VoiceLab, Saakshi, Brand Studio, voicebridgeai, Voice Action Gate, TechSəs, Voxrede, Veritas, RevenueFlow (51 коммит), Second Listen (47), Readdy AI (38), claim-intake (30). Это примерно 12–14 проектов — реальный круг конкурентов за 5 призовых мест.

Остальные 30 — это либо тонкая обёртка над Voice Agent API (Tourist translator — 4 KB, Speech-to-Maya — 4 KB, AuraCommand — 6 KB, Clinic Scheduling — 10 KB), либо аккуратный, но небольшой прототип.

### 3. Раздутый объём — тоже красный флаг

SmartLink: 3,5 MB из которых 50% HTML — почти наверняка закоммичены сборки/вендоренные ассеты. VerbaTrace: 1,6 MB «JavaScript 100%» без TypeScript — вероятно, бандлы в репозитории. Судья-инженер, открыв такой репозиторий, увидит не масштаб, а неаккуратность.

Оптимум по восприятию: 100–500 KB чистого исходника, читаемая структура, отдельные папки для сервера/клиента/тестов.

### 4. Отсутствие CI — повсеместно

Ни у одного из 45 проектов нет работающего GitHub Actions по теме (единственная папка `.github` нашлась у репозитория, который вообще не относится к проекту). Ни у кого нет CI, который бы запускал тесты на каждый push.

Тесты в каком-то виде есть у ~17 проектов, но это чаще всего один-два файла. Значит: рабочий CI-бейдж «tests passing» в README — дешёвый и абсолютно уникальный сигнал качества на этом поле.
