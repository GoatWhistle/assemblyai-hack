## Суть челленджа

«Build voice AI agents on AssemblyAI» — собрать голосового агента на реалтайм-технологиях AssemblyAI. Каждый проект обязан использовать AssemblyAI. Два пути на выбор:

### Путь 1: Voice Agent API
End-to-end голосовой агент через одно подключение, AssemblyAI держит весь ядровой voice-стек.
- Speech-to-text на Universal-3 Pro
- LLM-роутинг и голосовой вывод
- Turn-taking и voice activity detection
- JSON-Schema tool calling
- Оптимизирован под быстрые естественные взаимодействия

### Путь 2: Realtime Speech-to-Text API
Реалтайм-STT как фундамент, вся оркестрация своя.
- Real-time STT по WebSocket
- Субсекундная транскрипция
- Мультиязычное распознавание
- Свои LLM и TTS
- Больше контроля над архитектурой агента

AssemblyAI позиционируется как Voice AI infrastructure company; её модели стоят за Granola, HeyGen, Ashby, ClickUp.

## Критерии судейства

1. **Application of Technology** — насколько эффективно выбранные модели интегрированы в решение.
2. **Presentation** — ясность и убедительность презентации проекта.
3. **Business Value** — влияние и практическая ценность, вписанность в бизнес-области.
4. **Originality** — уникальность и креативность решения, демонстрация нетривиального поведения.

Все четыре критерия равнозначны в описании — нет весов. Очки лидерборда на оценку не влияют («Points do not affect submission evaluation»).
