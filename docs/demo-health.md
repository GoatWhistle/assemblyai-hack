## Что из этого следует для нас

1. **Примерно каждый пятый проект теряет очки на технической ерунде.** Мёртвый Render/домен, HF Space под авторизацией, ссылка на дашборд Vercel вместо приложения. Это не вопрос таланта — это вопрос того, что никто не проверил ссылку после сабмита.
2. **Render free tier засыпает.** Три из четырёх нерабочих демо — на `onrender.com`. Холодный старт Render на бесплатном плане занимает 30–60 секунд, и часть инстансов просто умерла. Для голосового агента с WebSocket это фатально: судья ждёт 50 секунд, слышит тишину, закрывает.
3. **Вывод для нашего хостинга:** фронтенд — Vercel/Cloudflare Pages (мгновенный CDN), WebSocket-бэкенд — платный always-on инстанс (Fly.io / Railway / Cloud Run с min-instances=1). Плюс страница-заглушка, которая честно говорит статус, если бэкенд недоступен.
4. **Обязателен fallback-режим для судьи.** Если микрофон недоступен, нет разрешения браузера или бэкенд лежит — должен быть режим воспроизведения записанной сессии по заготовленному аудио. Saakshi это предусмотрел («judge-solo mode»), и это правильный ход, который стоит повторить.
5. **Проверять ссылку нужно за час до дедлайна, с чужого устройства и в инкогнито.** Один из лидеров по голосам указал в качестве демо вообще чужое приложение (`ai-cover-letter`) — этого никто не заметил до сабмита.
