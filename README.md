# assemblyai-hack

Подготовка к [AssemblyAI Voice Agent Hackathon](https://lablab.ai/ai-hackathons/assemblyai-voice-agent-hackathon) (1–30 сентября 2026, дедлайн 30 сентября 18:00 MSK).

Исследование поля, разбор конкурентов и выбор кейса — в **[docs/](docs/README.md)**.

## Коротко

- **Берём:** [RxGate](docs/cases/rxgate.md) — голосовой приём рецептов, который не пускает в заказ значение без подтверждения валидатором или голосом.
- **Резерв:** [Bridgekeeper](docs/cases/bridgekeeper.md) — переключаемся, если на дне 2 диаризация уверенно различает три голоса.
- **Почему шансы есть:** 720 команд → 45 сдавших → серьёзных около десяти → 5 призовых мест. При этом 12 из 45 имеют мёртвое демо, 44 из 45 не измеряли латентность, CI нет ни у одного.
- **Главный рычаг:** AssemblyAI в середине хакатона опубликовала рамку оценки голосовых агентов (Entity Error Rate, caller repeat rate, процентили латентности, close codes) — её не применил никто.

Полный тирлист идей и навигация — [docs/README.md](docs/README.md).
